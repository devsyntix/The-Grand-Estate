# The-Grand-Estate

A premier luxury real estate web application showcasing luxury villas in North Bangalore by DevSyntix Builder.

## 🌟 Overview
- **Project**: The Grand Estate
- **Developer**: DevSyntix Builder
- **Typologies**: 3, 4 & 5 BHK Private Luxury Villas
- **Location**: North Bangalore, Karnataka

## 🚀 Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Animation**: Framer Motion
- **Linter**: Oxlint

## 🛠️ Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
